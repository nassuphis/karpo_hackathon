# Legacy Plan Archive

This directory holds top-level Markdown files that are no longer part of the active PolyPaint reference set.

Archive criteria used for this pass:

- the file already described itself as `historical`, `legacy`, or `superseded`
- or it documented a migration/review state that is no longer the current implementation

Files kept at the repo root are still treated as active reference docs, current behavior docs, or open design notes.

This archive is intentionally conservative. If a file is still plausibly active, it stays in place until there is a clearer replacement.
